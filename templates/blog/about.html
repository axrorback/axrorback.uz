Men haqimda

Salom! Men Ahrorjon, yuqori yuklamali va samarali backend tizimlar yaratishga ishtiyoqi baland bo'lgan dasturchiman.

Asosiy e'tiborim Python ekotizimi (Django, FastAPI) orqali murakkab biznes mantiqlarini xavfsiz va tezkor API ko'rinishida amalga oshirishga qaratilgan. Hozirda Acharya Universitetida bilimlarimni akademik darajada mustahkamlamoqdaman.

Texnologik stack

PythonDjango, Flask, FastAPI
DatabasePostgreSQL, Redis
AutomationAiogram, Bots
DevOpsDocker, Nginx
OSLinux, Bash
FrontendJS, Bootstrap

Qiziqishlarim

Sun'iy intellekt integratsiyasi, mikroservislar arxitekturasi va ma'lumotlar xavfsizligi mening asosiy fokusimda. Bo'sh vaqtimda yangi texnologiyalarni test qilishni yoqtiraman.

Asosiy maqsad

Global miqyosdagi muammolarni hal qila oladigan, barqaror va kengayuvchan platformalar yaratish hamda O'zbekiston IT ekotizimiga hissa qo'shish.

Nimalar bilan shug'ullanaman?

  • Xavfsiz va yuqori samaradorlikka ega RESTful API lar ishlab chiqish.
  • Ma'lumotlar bazasi so'rovlarini optimallashtirish.
  • Docker konteynerizatsiya orqali loyihalarni deploy qilish.
  • Biznes jarayonlarni avtomatlashtiruvchi Telegram ekotizimlari.
